# Richmond Workshop

This repository contains materials for a workshop on AI workflows held at the University of Richmond. It uses a small set of historical documents as sample data for demonstrating AI-assisted workflows.

## Source Documents

The PDFs in [`source documents/ASR/`](source%20documents/ASR/) are Seventh-day Adventist Annual Statistical Reports (ASR), 1867–1876, downloaded from the General Conference Office of Archives, Statistics, and Research:
